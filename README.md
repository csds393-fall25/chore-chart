# chore-chart
This is a project for CSDS 393 Software Engineering. It is a chore chart system with a way to randomly assign chores for different members of a household to complete. Completing chores earns an in game currency that a person can use to upgrade their avatar.

You can access this project at: https://chore-chart-rho.vercel.app *

*We are currently in the process of migrating to Supabase, so users can not log into an account right now.
